# 2026-10-15 — PoliMusic classic ASP app (build + validation complete)

## What was built
Spotify-like music app in classic ASP/VBScript at repo root `webapppolimusicv1_asp`:
- **Pages**: login.asp, logout.asp, default.asp (tabs: songs/artists/albums/playlists),
  search.asp, artist.asp, album.asp, playlist.asp, admin/{songs,artists,albums}.asp, api/play.asp
- **Includes**: db.asp (conn + helpers + pure-VBScript SHA-1), songs.asp (song table/JSON),
  layout.asp (topbar/player/modal), footer.asp
- **Assets**: css/styles.css (palette #FB5607/#8338EC/#212529/#E9ECEF), js/app.js (HTML5 player)
- 14 missing images generated by build_media.py (gradient placeholders, Pillow)

## Key decisions
- Roles via Session("USER_TYPE"): 0=normal, 1=admin; admin gets CRUD, users get search + own playlists
- Parameterized ADODB.Command everywhere; HTML escaping via H(); ToInt() for ids; PRG + flash messages
- Provider fallback chain in GetConn() (MSOLEDBSQL → default → SQLOLEDB → SQLOLEDB no-encrypt)
- Passwords: plaintext or SHA-1 hex (username1 stores SHA-1 of "12345678")
- VRoot() resolves app root from APPL_MD_PATH so `~/` media paths work as app URLs

## Validation performed (no IIS locally)
- `_tests/lint_asp.py` — structural linter (directives, <% %> balance, HTML pairing,
  VBScript block structure). Handles: single-line If…Then, Exit Sub/Function/For/Do,
  `On Error Resume Next` (phantom Next), `End X` keyword double-count, self-closing SVG
  tags, split Do…Loop across <% %> blocks, include fragments exempt from @Language check.
  Self-tested against a deliberately broken file (6/6 defects detected). All 15 ASP files pass.
- `_tests/sha1_emulation.py` — faithful Python emulation of the VBScript SHA-1 (cscript is
  blocked by LOLBin policy); matches official vectors + hashlib. ALL TESTS PASSED.
- `_tests/gen_preview.py` + `_tests/shot_preview.js` — static previews of 8 views
  (seed data from BDD_PoliMusic.sql) screenshotted via Playwright Chromium
  (Edge is blocked in this env; installed `playwright` in the managed node workspace,
  `playwright install chromium`). Zero console errors on all 8 pages.

## Bug found via screenshots (FIXED)
`.modal-backdrop { display: grid }` overrode the `hidden` attribute → add-to-playlist modal
showed on load and could not be closed. Fixed with `[hidden] { display: none !important; }`
at the top of css/styles.css.
